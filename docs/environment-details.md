# 环境详情 · v0.11.0

入口：总览环境指标标题右侧的 **环境详情 ›**。首页不新增五张指标卡，详情复用同一份区域天气和获取时间；打开页面不额外请求，手动“刷新天气”沿用现有天气/空气刷新流程及 30 秒间隔。

| 指标 | 显示 | 数据含义 |
| --- | --- | --- |
| 体感温度 | °C，1 位小数 | 提供方计算的体感参考，不是手机温度计实测，也不代表个人实际感受 |
| 露点温度 | °C，1 位小数 | 空气冷却到水汽饱和的温度参考；不单凭此值判断会下雨或室内结露 |
| 能见度 | 小于 1000 m 用 m / 1 位小数；否则 km / 2 位小数 | 区域水平能见距离，不是手机相机测距或实际道路视野保证 |
| 云量 | 0–1 比例转为百分比 | 天空云覆盖比例，不据此推算手机光照或紫外线 |
| 阵风风速 | m/s，1 位小数 | 区域短时增强风速；不冒充手机附近的风，也不臆造其统计时间窗或当日最大值 |

## 数据和页面边界

- 所有数值来源均为 `REGIONAL_API`，沿用和风归因。体感值的计算属性单独说明，不误写成手机实测或本机算法估计。
- 读取当前 `GET /weather/v1/current/{latitude}/{longitude}` 已返回的 `feelsLike`、`dewPoint`、`visibility`、`cloudCover`、`windGust`。无需新增 API 授权或调用次数，不接入天气指数接口。
- 只接受文档规定的 °C、m、m/s 单位；体感和露点允许负数；距离和阵风必须非负，云量必须为 0–1，非有限值、缺失值、未知单位保持 `—`。不通过温湿度或平均风速自行补算。
- 零值正常显示；演示模式的五项详情均为空，并明确标注演示模式，不生成伪实况。
- 使用总览的 `EnvironmentViewModel + StateFlow`，只投影出详情字段，不创建重复仓库和网络加载器。不增加位置或传感器监听、权限、后台任务、第三方依赖。
- 显示原获取时间和设备时区，获取时间不等于现场观测时间。较早数据（10 分钟或以上）或时间异常有提示；离线失败保留同一区域缓存和错误信息，不刷新旧时间。
- 旧缓存缺少新字段可正常进入，显示占位和刷新说明。旧历史记录不回填；网络刷新成功后才可能获取真实新增数据。
- 新手动快照保存天气响应中的详情指标，记录和 CSV 保留值、单位、来源、描述与原时间。Room schema v1、CSV 19 列不变；未扩展可选历史曲线和差值计算。
- 详情页支持返回、设置往返、进程重建与三套主题。界面时间有效性检查每分钟执行，仅在前台运行；新快照到达时同步更新判断。

官方字段核对：2026-10-18，[和风实时天气](https://dev.qweather.com/docs/api/weather/weather-current/)。
