# 历史筛选、快照对比与可选趋势 · 0.7.0

本版以找回记录、并排比较两份快照为主，曲线作为可选入口。历史快照来自用户手动保存的区域 API 数据；零散快照可以比较各次获取的结果，但不能反映这段时间内完整、连续的环境变化，也不能据此解释原因。

包名仍为 `com.ambient.app`，版本 `0.7.0`（versionCode 9）。已有保存、备注、删除与 CSV 功能继续使用，数据库仍为 schema v1，不需要重建或清空历史。

## 区域与日期筛选

在“记录”页打开筛选卡：

1. 点击“区域”，选择“全部区域”或一个已有区域。按记录里保存的区域名称精确匹配，不模糊搜索、不自动合并不同名称。
2. 点击“日期”，选择“全部日期”“今天”“近 7 天”“近 30 天”，或点击“自选日期”选取开始与结束日期。“近 7 天”包含今天及此前 6 个本地日期，“近 30 天”包含今天及此前 29 个本地日期。
3. 日期按手机本地时区中的**数据获取日期**筛选，开始与结束当天均包含。保存日期不参与日期匹配；今天保存的旧缓存仍属于旧数据获取日。
4. “重置筛选”回到全部区域、全部日期。没有匹配时显示独立空状态，不代表数据库已空，也不会删除其他记录。

筛选后的列表继续按保存时间从新到旧排列。区域选项来自全部已有记录，不因当前日期范围没有匹配而消失。Material 日历以 UTC 午夜编码日期，应用先解码为日历日期，再按手机本地日期边界查询，避免直接把选择器毫秒值当成本地时间。

历史只保存区域名称，没有经纬度；因此同名但坐标不同的历史快照无法进一步区分。这里的“同一区域”指保存名称相同，不证明是同一个精确位置。本版不为解决分组问题而新增位置或轨迹存储。

## 两份快照并排对比

1. 在记录卡点击“选择对比”，第一份记为 A、第二份记为 B，最多选择两份。
2. 可以切换区域或日期继续选择，A/B 选择不会随筛选清空。第三份会提示先取消一份，顺序不会悄悄替换。
3. 点击“对比这两份快照”，查看两侧区域、原获取时间、保存时间、独立观测时间（若有）、缓存标记、备注，以及全部指标的原值、单位、来源与说明。一侧缺少的指标保留缺失，不填零。
4. 可打开 A 或 B 的完整快照详情；点击“已选 A/B · 取消”或“清空选择”重新选择。成功删除所选记录后会移除该选择；记录在读取期间不存在或失败时明确提示，不继续展示旧对比结果。

差值固定为 **B − A**，表示绝对数值差，不是相对百分比。A/B 按选择顺序排列，B 不保证在时间上晚于 A；要判断前后关系，应同时看两侧获取时间。

只有同时满足下列条件才显示计算差值：

- 两份记录的区域名相同且非空，数据获取时间不同，均不含演示数据。
- 两侧存在该指标，来源均为区域环境 API，单位完全一致，不自动换算单位。
- 指标属于已知标量：温度、湿度、气压、AQI、PM2.5、PM10、风速或紫外线指数；风向、海拔等只保留并排展示。
- 两侧都是可解析的有限数值，并符合指标有效范围；AQI 还要求标签相同，避免将不同标准或标签直接相减。

例如相对湿度 A 为 50%、B 为 60%，显示 `+10.00 个百分点`，不写成增长 10%。风向文字或角度不按普通标量相减。不同区域仅并排展示；同一区域且获取时间相同（包括重复保存缓存）属于同次获取，不计算时间变化。即使符合差值条件，也**不说明变化原因**，不把某次移动、运动或操作解释为环境变化的原因。

## 区域趋势是可选入口

点击“区域趋势 · 可选”，可切换温度、湿度、海平面气压和 AQI。默认不占据记录列表，也不会启动额外采集。

- **每次只展示一个区域。** 筛选已选区域时使用该区域；全部历史只有一个区域时自动采用它；有多个区域时先要求选择，不把不同城市拼成一条曲线。
- **横轴为原始获取时间。** 各点按真实时间间隔安排，不等距排列，不按保存时间绘图，也不把获取时间冒充服务观测时间。点详情分别保留获取、保存和独立观测时间。
- **同次获取合并。** 同一区域相同获取时间只形成一个点，不论保存了几份缓存。存在非缓存版本时优先使用它；只有缓存版本时保留缓存标记。去重只影响趋势展示，不删除列表中的原始快照。
- **缺失保持缺失。** 找不到指标、单位不符、来源不符或数值无效时保留该时间点为空点，并中断连线，不补零、不插值、不用临近读数代替。
- **窗口有上限。** 最多展示当前区域、日期范围内最近 120 个不同获取时间，包含缺失时间点；有更早记录时明确提示，可缩小日期范围查看更早部分。
- **单点不判断趋势。** 只有一个获取时间点、只有一个有效读数或全部缺失时分别说明，不能因为单点存在就显示“上升”“下降”等结论。
- **点可追溯。** 点击图上时间点，或使用“上一点”“下一点”查看原值、单位、来源、时间和缓存状态。纵轴自动缩放，视觉起伏不等于很大幅度的物理变化。

曲线连线只用于比较已保存的点。两点相隔很久时，中间没有持续采集；曲线不表示这段间隔的实际过程，不做预测或因果分析。区域天气与手机附近的局部光照、运动、室内温湿度也不是同一类测量。

## 状态、导出与实现边界

筛选与 A/B 选择保存在 ViewModel 中，可跨页面切换和屏幕旋转继续使用；结束进程后重置，不是长期写入的偏好。快速切换日期、区域或指标会取消旧查询，界面按实际查询条件区分加载与结果，避免把旧数据短暂标成新筛选结果。读取失败显示重试入口，不清空数据库。

列表在 Room 中按区域名和获取时间范围筛选，只读摘要列。对比按两个 ID 读取完整快照。趋势在 IO 调度器执行，在 Room 事务中每批读取 64 条，检查取消并保留有限数量的获取时间点；不把所有历史完整快照长期装进界面内存。没有新增第三方库、API 请求、定位、网络刷新、传感器监听、定时任务或后台采集。表结构保持 v1，未启用破坏性重建。

**CSV 始终导出全部本机历史。** 当前区域/日期筛选和 A/B 选择均不改变导出范围；筛选无匹配但本机仍有记录时仍可导出。暂未提供“仅导出筛选结果”，也不支持 CSV 导入恢复。CSV 格式、明文范围和失败处理见[导出说明](csv-export.md)。

本机历史仍是 App 私有目录的普通 SQLite 数据库，尚未加密，且排除备份；卸载或清除 App 数据会删除历史。清除天气凭据与缓存不会删除历史。本版没有改变这些存储边界，详见[环境快照与历史记录](history.md)。
