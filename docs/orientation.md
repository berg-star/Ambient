# 手机指南针与倾斜水平仪 · 0.8.0

探测页新增两张仪表，沿用三套渐变主题、深浅色和现有采集开关。角度是基于手机传感器的计算结果，不是区域天气 API 数据，也不是独立角度传感器的直接实测。没有新增依赖、权限、定位、网络请求或后台任务，不把这些数据保存到环境历史。

## 使用

- **手机指南针**：显示当前屏幕上边缘在水平面上的方向，以磁北为 0°，东为 90°，南为 180°，西为 270°。北针和方位盘随读数旋转，上方固定标记表示屏幕朝向；它与区域风向罗盘各自独立。359°/0°交界不使用旋转动画。
- **倾斜水平仪**：左右正值表示屏幕右边缘抬高，前后正值表示屏幕上边缘抬高。横竖屏后仍按当前屏幕解释。两个数值是边缘相对水平面的倾角，范围 −90°～90°，不是陀螺仪角速度积分。
- 正面朝上且两个角的绝对值都小于 1°时显示“接近水平”，不宣称已经专业校准。屏幕朝下隐藏气泡，避免翻面平放被当成正面水平；数值仍保留并解释翻面状态。
- 气泡向较高一侧移动，显示半径在约 30°处饱和，超出时贴近边缘；具体角度以数值为准，不截断数字、不强制归零。数字显示到 0.1°，仅统一舍入后的正负零格式，不修改底层计算角度。
- 屏幕上边缘接近竖直时，其水平投影太小，指南针显示无明确方向，提示放低手机；水平仪仍可显示倾角。
- “了解”提供物理含义、支持的硬件、计算来源和打开说明时固定的事件时间、状态，便于核查而不让文字不停刷新。

磁北与地图常用的真北不同，本版不做磁偏角修正，不为指南针请求定位。静置、运动、磁性配件、金属和设备自身校准都会影响结果；设备精度状态不说明具体干扰原因，也不保证等待或完成某个动作后就会改善。

## 能力与来源

启动前按实际存在的能力选择一条路线，不假设每部手机都提供全部传感器：

| 路线 | 指南针 | 水平仪 | 页面来源 |
| --- | --- | --- | --- |
| Android `TYPE_ROTATION_VECTOR` | 支持磁北方位 | 支持 | Android 旋转向量 · 系统融合 |
| 加速度计 + 磁场 | 通过 Android 旋转矩阵计算 | 以加速度方向估计 | 加速度计 + 磁场 · 算法估计 |
| 仅加速度计 | 不提供方向 | 估计倾角 | 加速度计 · 倾角估计 |
| 缺少上述能力 | 明确不可用 | 明确不可用 | 设备不支持 |

不使用 `TYPE_GAME_ROTATION_VECTOR` 冒充磁北方位，因为它没有磁北参考。加速度路线受运动影响，接近自由落体时拒绝用微小噪声生成姿态。注册失败显示错误并完整注销本次姿态订阅，重试使用总采集开关；不会偷偷换路线却继续显示旧来源。

指南针单独显示设备报告的未知、低或不可靠精度。状态为“不可靠”仍与“启动失败”区分；水平仪不会因为磁场精度状态而提示采集异常。旋转向量额外提供方位误差角时才显示，负值或缺失保持未知，不当作误差为零，也不把估计误差角当作保证上限。模拟器明确显示“虚拟数据”，不能用来验证真实磁北或实体机精度。

## 采集与坐标

`AndroidOrientationRepository` 使用独立 SensorManager 订阅和 HandlerThread；姿态与原始读数互不重置，切换去重力/含重力模式不会打断指南针或水平仪。请求采样间隔 50 ms，按传感器事件时间戳约每 100 ms 发布一次最新结果；不累计无限样本，不建立额外曲线。两张卡各自订阅 StateFlow，姿态更新不会驱动整个探测页重组。

采集开关、页面可见性和 Activity 恢复状态共同控制监听。离页、打开设置、后台或手动暂停会注销姿态监听、移除定时回调并退出线程。暂停明确标记最后结果；恢复清空旧结果，等待新事件。屏幕旋转由 DisplayListener 感知，暂停结果若属于旧屏幕坐标系会清空。

首次 5 秒没有有效事件会提示等待读数；没有必须静置若干秒才能解除的门槛。有结果后超过 2 秒无有效更新会隐藏仪表，新的有效事件可立即恢复。精度回调不产生测量时间，也不让过期值恢复为实时值。乱序、重复、未来、陈旧和旧会话事件被忽略；复制事件数组后计算。

加速度与磁场回退只组合时间差不超过 1 秒、且各自未超过 2 秒的事件，并分别保留两源时间。使用较新的源事件作为计算结果时间，过期判断同时检查两源，不伪造同步采样。查询、算法和读数均不以 UI 刷新时间替代传感器事件时间。

Android 传感器坐标不随屏幕旋转。纯 Kotlin 数学层接受设备到世界的旋转矩阵（世界 X 东、Y 磁北、Z 天），再换到当前屏幕的右边和上边。R90 对应屏幕右为设备 −Y、屏幕上为设备 +X；与 Android `remapCoordinateSystem` 对照验证，覆盖四种旋转及倒置，不以 Activity 的“横屏”布尔值代替真实显示旋转。

## 验证与安装包

Debug 主包和测试包构建通过，195 项 JVM 测试、47 项 Android 仪器测试通过；Android Lint 0 错误、5 条已有依赖版本提示。新增测试覆盖已知姿态、磁北边界、四种屏幕旋转、正负倾角、翻面、近竖直、非法输入、传感器缺失、注册失败、事件复制与节流、配对时效、精度未知、暂停/恢复和旧会话隔离。Android 测试直接使用 SensorManager 的矩阵与坐标转换接口作独立对照。
