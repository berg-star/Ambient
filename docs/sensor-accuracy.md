# 0.3.1 传感器精度提示修正

## 真机反馈与结论边界

用户在 Pura 70 Pro 上反馈：含重力模式没有这条警告；去重力模式曾静置十几秒后恢复，也曾等待数分钟仍有警告。静置时接近 0，移动时读数会变化。截图显示合成值 0.05 m/s²，三轴显示为 0.00、0.02、0.04，最近约 5.9 秒范围为 0.01～0.11 m/s²，精度状态为不可靠。

这些现象说明采集到了有运动响应的数值，与静置下存在小幅噪声或偏移相符；不能证明测量精度合格，也不能确定硬件故障、外部干扰、自动校准或驱动行为中的哪一种是原因。界面展示经过舍入，不能用显示的三轴值精确复算未舍入的模长。曲线纵轴自动缩放，小幅变化也可能看起来明显。

旧版把平台精度警告放入采集错误字段，并统一补充“远离干扰源”，会将有读数的通道误标为“采集异常”。检查代码未发现固定等待倒计时，未确认存在精度恢复后警告粘滞的缺陷。不能要求用户等待固定时长，也不按时长推定读数可信。

## 修正

- 采集错误仅用于启动失败、未收到有效首个事件或无效数值等问题。
- 有有效读数时，精度 0 保留“采集中 · 精度不可靠”和明确的参考用途提示；精度 1 显示较低。不得把精度 0 当作“未提供”或直接忽略。
- 每个后续已发布数据事件、每次精度回调都可更新精度；真实采集错误只能由有效事件恢复，不能被精度回调清除。
- 去掉无依据的“远离干扰源”。不强行归零、不滤出假零、不隐藏警告、不增加后台监听或固定等待时间。
- “了解”中新增可长按复制的系统状态详情：通道、名称、厂商、当前精度、最近处理的数据事件精度、最近精度回调、事件时间及 XYZ。打开时保存界面快照，可点击“刷新状态”更新，防止频繁变化打断复制。事件和回调分开保留，后者可能尚未收到；卡片数值显示仍最多约每秒 10 次。仅在本机展示，不写日志、不上传。
