# 风向小罗盘 · 0.4.1

风向文字旁新增小罗盘，使用当前主题强调色。固定上北下南、左西右东：亮点标记风从哪里来，箭头从亮点朝中心吹入。文字标注“来自”，点击风向可查看放大罗盘和物理含义。它是区域风向示意，不是手机指南针，不会随手机转动，也不会启动磁场或定位监听。

## 数据规则

- 网络模式使用和风 `wind.direction.degree` 的实际角度，不用“东东北”等方位名称的中点代替服务数值。字段定义见[实时天气官方文档](https://dev.qweather.com/docs/api/weather/weather-current/)。
- 北为 0°、东为 90°，角度顺时针增加。亮点沿该角度位于罗盘边缘，箭头由边缘指向中心，表示空气从该方向吹入。
- 无风向、不定风向、缺失、非有限数及超出官方范围的角度，不画箭头；不会默认成北风。
- 旧版缓存没有角度时继续显示原来的风向文字，提示“刷新以显示箭头”；不丢掉缓存，也不编造角度。刷新获取新数据后会缓存实际角度。
- 演示模式的东北 45°仅是固定演示值，仍标注“演示数据”。
